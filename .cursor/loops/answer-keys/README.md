# Answer keys

Filled per-story answer keys live here as `STORY-xx.md` (or a clear story id from the stories source named in CONTEXT).

Copy from `../ANSWER_KEY_TEMPLATE.md`. Set **Status** to `approved` only after a human has signed off. The `story-loop` skill will not start a coding Cloud Agent against a draft key.

See `../PLAYBOOK.md` for the full loop contract.
