# Diagrams

System, sequence, and data diagrams that support architecture and product docs.

Prefer diagrams that match `docs/architecture/` and `docs/mvp/`. Framework-how diagrams live here so scaffolds and decks share one mental model.

| Diagram | File | Use |
|---------|------|-----|
